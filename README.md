# UkayPro Business Suite

Inventory, live selling, sales, and automation system for ukay-ukay stores.

## Structure

```txt
frontend/   Static web app
backend/    Node API scaffold
shared/     Shared constants and schemas
docs/       Project documentation
```

## Quick Start

Open `index.html` from the project root to redirect to the frontend.

Run the backend API:

```bash
npm start
```
